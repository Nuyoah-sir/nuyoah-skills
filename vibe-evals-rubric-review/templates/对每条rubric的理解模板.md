## 三、判分口径说明（与打分文件一致）

1. **二值判分**：每条 rubric 1 分，0/1 二值（满足=1，不满足=0），**不使用权重**（用户建议，且各条目均为 prompt 要求或合理预期，重要性相近；Must have / Nice to have 的区分仅在条目元数据中体现，不参与加权）。
2. **“未经纠正时”**：以模型当轮自主产出为准（未经评测方纠正即正确才得分）。
3. **无产物即 0**：模型没有输出产物，所有条目一律 0 分，总体分 0（{本批各模型产物情况说明}）。
4. **总体分口径**：总体 rubrics 得分 = 得分数 / 总条目数（{M}）。**没有实现 prompt 重要实现（含无输出产物、几乎未实现预期效果）即打 0 分**。
5. **实测优先原则**：凡可实测的玩法类条目，一律以实测为准判分；“代码层面有实现”不等于达标。{本批机器自测情况}，但人工实测状态见记录.txt——打分文档中预留“人工实测意见”栏，与静态证据冲突时以人工实测为准。
6. **待裁定口径（见 1.1）**：{①②③…每项一句话索引；打分由打分人裁定，所有模型采用同一口径。}
7. **证据链**：每条打分基于三路证据——①模型最终产物源码（file:line）；②轮次留痕（轮次快照 + 模型对话记录 json）；③机器自测实跑 + 人工实测（打分人）。本文件所有 file:line 引用均经抽查核验。
