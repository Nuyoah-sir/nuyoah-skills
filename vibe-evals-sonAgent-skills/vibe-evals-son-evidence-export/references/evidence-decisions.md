# 证据判断矩阵

> 适用范围：只导出证据（本技能）时使用本矩阵。完整评测流程（`$vibe-evals-son-complete-eval`）的观测与裁定判据见该技能的 `references/observation-decisions.md`，两者不得混用。

| 情况 | 可以做什么 | 不可以做什么 | 输出 |
|---|---|---|---|
| 找到名称相似的函数 | 继续追入口、调用链和状态效果 | 仅凭函数名判 1 | 静态倾向或继续取证 |
| 全局搜索没找到 | 检查文件清单、入口和等价实现 | 把“没找到”写成“确认缺失” | 证据不足则 null |
| 明确缺入口/文件/调用 | 用 inventory + static 记录确认缺失 | 只写“似乎没做” | 可倾向 0，direction=`confirm_missing` |
| 静态实现存在，行为未测 | 给静态倾向并降低置信度 | 写“功能已通过” | 行为仍需测则 null/人工检查 |
| 自测 PASS | 保存实际脚本副本与哈希、环境、原始输出、同 rubric 结构化断言，核对覆盖 | 把无脚本或无场景绑定的 PASS 当充分证据 | 场景对应才可支持 |
| 自测 PASS、独立探针 FAIL | 保留两者，解释覆盖差异 | 丢弃失败结果 | 倾向 0 或待裁定 |
| 人工实测 FAIL，代码看似实现 | 原文 + 静态 + 冲突裁定 | 用代码覆盖人工记录 | null + `ADJ-*` |
| 人工记录未说明轮次 | 找上下文、快照或询问 | 自行认定轮次 | null + `ADJ-*` |
| R1 失败，R2 修复 | 分别记录并写修复轨迹 | 用 R2 给 R1 得分 | 各轮各判 |
| R1 快照缺失，只有最终代码 | 登记缺口 | 宣称验证“未经纠正时” | partial/missing + null |
| 对话缺失 | 做产物可证明项，并登记 model 级 material gap | tokens/debug/首问填 0，或静默略过缺口 | 过程证据 null；本机逐项决定是否带限制继续 |
| 无安全沙箱 | 静态取证 | 宿主直接跑 | `skipped_no_isolation` |
| 测试触网/读凭据/跨目录写 | 立即停止并记安全事件 | “只跑一次看看” | `skipped_unsafe` |
| Subjective/视觉/手感 | 截图、步骤、人工记录、机器倾向 | 伪造肉眼体验 | `human_check_needed=true` |
| criterion 两种合理解释 | 对所有模型建立同一裁定 | 按模型分别放宽 | null + `ADJ-*` |
| 无输出或几乎未实现 | 提供模型级事实，标兜底候选 | 逐条编造 0 原因 | 本机确认 |
| 用户要求不要留空 | 解释 null 是证据结论 | 为省事填 0/1 | 保留 null |
| 子代理说完成 | 运行校验器 | 直接生成 READY | 校验结果为准 |

## 0、1、null

倾向 1：对应轮次事实被直接支持，至少一条 `support`，无关键反证、未决口径或必需人工体验。

倾向 0：安全实测失败、对应轮源码明确相反，或以完整 inventory/入口/调用链确认缺失；至少一条 `refute` 或 `confirm_missing`。

必须 null：只是没找到、行为须动态验证但无隔离、轮快照缺失、证据冲突、口径多解、缺人工体验、引用/哈希不可验证。

## 置信度

- 高：直接安全实测，或完整对应轮静态证据，无冲突。
- 中：静态充分但未动态验证，或测试覆盖接近而不完全等同 rubric。
- 低：间接线索、缺快照、对话局部失败、人工记录轮次不明。

`coverage=missing/unsafe_to_test` 不得用高置信度。

## 裁定项和兜底

裁定项包含问题、歧义原因、证据 ID、适用 rubric、全模型统一性、建议与备选口径及分数影响。远端 `resolution` 必须为 null。

“几乎未实现”是高影响口径。远端只提交文件数、总字节、入口、核心链路、可启动证据与重要要求覆盖情况；若只是部分功能缺失不得使用兜底。
