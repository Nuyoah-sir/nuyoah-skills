# 观测与裁定决策表

遇到下表任一行，照最后一列执行。**没有任何一行允许你自行放宽标准。**

| 情况 | 判据 | 允许的关闭方式 | 必须记录 |
|---|---|---|---|
| 客观存在性（presence/absence/count/literal_text/exact_color/显式相对位置/显式尺寸） | 条目被分类为客观类，且引用片段能在条目文本里逐字找到 | 两读一致的高置信机器读图 | 两条读的 invocation/session、问题与提示摘要、原始回答、事实陈述 |
| 主观或政策歧义 | 包含美观/自然/清晰/可接受/可用等形容，或挂了 `ADJ-*` | 只能由真人见证关闭 | 真人的观察步骤、预期、实际、被观察版本、原始确认词 |
| 两读冲突 | 结论不一致、或 `conflict=true` | 升级人工 | 冲突点与两条原始回答 |
| 单读 | 只有一条读 | 不允许关闭 | 缺哪一条读 |
| 同一会话/同一调用 | invocation 或 session 相同 | 不允许关闭 | 两个 id |
| 第二条读复述第一条 | 第二条原文包含第一条的结论 | 不允许关闭 | 两条原文 |
| 低置信 | 任一读不是 high | 升级人工 | 置信等级 |
| 视觉结论与静态证据方向矛盾 | 视觉判定与 `support`/`refute`/`confirm_missing` 相反 | 升级人工 | 两个方向 |
| 缺 target/feedback 素材 | 冻结清单里没有对应文件 | 记为材料缺口 | 缺哪个素材、影响哪些条目 |
| 无法渲染（不安全 SVG / 主动内容 / 无渲染器） | 白名单拒绝或 `NO_QUALIFIED_RENDERER` | 人工见证 | 具体错误码 |
| 缺可选材料 | 缺口 id 在 `gap-policy.json` 的 `known_optional` 内且前置条件满足 | 机械关闭 | 前置条件证据 |
| 缺语义材料 | 不在 `known_optional` 内 | 真人决议 + 限制说明 | 政策、决议人、时间、限制 |
| 现场没有真人 | 找不到可执行确认的人 | 停在退出码 5 | 需要真人的 slot 或条目清单 |

## 不许做的事

- 不许把 `null` 或未知分数当成 0 来"填满表格"。
- 不许用机器读图关闭主观条目。
- 不许把"没找到"写成"确认没有"。
- 不许替真人写确认词，也不许把机器结论记成 `decided_by: human`。
- 不许因为总数对得上就跳过逐条核对。
