# 机器读图提示模板

> **本文件里的 id、路径、答案、分数全部是虚构示例。** 不得把这里的任何具体内容复制进真实记录。

## 第一读（read_index = 1）

```
只描述你实际看到的内容，不要给通过/不通过结论。
素材：<冻结的目标素材 id> 与 <候选渲染 id>。
请回答：
1) 图中出现了哪些具体对象？
2) 每个对象的位置（用九宫格或相对关系描述）？
3) 对象之间的关系（上下/左右/包含/连接/颜色是否一致）？
4) 与目标相比，哪些具体细节不同？逐条列出，不要总结成一句"看起来不一样"。
```

## 第二读（read_index = 2）

换一个提问角度、换一次独立调用与独立会话，并且**不要**把第一读的结论放进提示或期望里。例如改为要求先逐对象清点、再逐项与目标比对。

## 记录时必须提供

- `invocation_id` / `session_id`（两次读必须不同）
- `question` 与 `prompt_sha256`（提示的真实摘要）
- `raw_response` 与 `raw_response_sha256`（原始回答的真实摘要）
- `fact`：一句可核对的事实陈述（不是结论词）
- `verdict`：0 或 1；`confidence`：只能 high；`conflict`：false
- `input_media_ids`：两次读必须完全相同，且同时包含目标与候选渲染

## 直接拒收的写法

- 只写"看起来没问题"、"符合预期"、"通过"；
- 第二次读的原文里出现第一次读的结论句；
- 提示是两个字符不同的同一条；
- 缺 `raw_response` 或缺任一 id。
