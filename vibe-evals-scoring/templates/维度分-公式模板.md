# 维度分（公式）· {批次标识}

> **G1/G2/S1 的定稿依据**：本文件由 `rubrics-{X}.json` 的 0/1 判定直接算出，是 **G1 指令与遵循 / G2 功能完整性 / S1 视觉审美** 三个维度分的唯一定稿来源；**G3 任务收敛效率与总体印象分仍按人工判分**（G3 按 debug 轮数），Rank 仍按总体印象分定档。

**口径**（《Coding Agent 人评标准 V 2.1》五、Rubric「Rubric与维度分数映射规则」，2026-09-22 版）

- 判定层：每条 criterion 只判 0/1，不给部分分；
- 计分层：`通过率 = k / n`（k = 该维度通过条数，n = 该维度总条数）、`原始分 = 通过率 × 4`、**`维度分 = 向下取整到 0.5 的倍数`**（用户 2026-09-22 定稿：标准原文写「向下取整」，同处又写「步长 0.5」，取到 0.5 的倍数）；
- 归类：按每条 rubric 的 `dimension` 字段归类，多选逐维度各计一次；
- 边界：缺 `score` 的条目列为未判定，**不计入分子分母**（不按 0 计）；未标 `dimension` 的条目只登记不计分。

**生成方式**（不要手算）：

```
py <本技能目录>/scripts/formula_dimension_scores.py <输出目录>/rubrics-*.json --out <输出目录>/维度分-公式.md
```
